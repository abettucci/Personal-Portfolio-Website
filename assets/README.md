# CV PDF

Arrastrá tu CV a esta carpeta y nombralo `cv.pdf`.

La página ya apunta a `assets/cv.pdf`, por lo que al refrescar vas a tener dos acciones visibles: **View CV** y **Download PDF**. Si preferís alojarlo en otro lado, cambiá `contact.cvUrl` dentro de `content.js` por una URL pública `https://`.
